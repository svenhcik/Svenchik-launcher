# Svenchik Launcher

Лаунчер Minecraft: Java Edition для Windows. Интерфейс: тёмные «стеклянные» панели, боковая панель с пиксельными блоками, фон по мотивам логотипа (Край, шпили, травяные острова). Python 3.10+, интерфейс — Qt Quick (PySide6/QML), готовый `.exe` собирается PyInstaller.

## Возможности

- Запуск Minecraft Java Edition (любая версия из манифеста Mojang, включая старые бета/альфа и снапшоты).
- Скачивание и установка версий: клиент, библиотеки, нативные библиотеки, ресурсы (с проверкой SHA-1/размера, докачка недостающего, работа без сети для уже установленных версий).
- Автоподбор Java: система → иначе автоматическая загрузка среды Mojang (Java 8 / 17 / 21 — какая нужна версии).
- Аккаунты: офлайн (ник) и Microsoft (device code flow), обновление токенов, несколько аккаунтов.
- Настройки: ОЗУ (мин/макс), путь к Java, аргументы JVM, папка игры, поведение лаунчера.
- Журнал: вывод лаунчера и самой игры в приложении и в `data/logs/launcher.log`.
- **Сборки с модами.** Fabric, Quilt, Forge, NeoForge ставятся в пару кликов; для старых версий — Legacy Fabric и Babric. У каждой сборки своя папка (моды, сохранения, настройки): `<папка игры>\instances\<сборка>`.
- **Каталоги Modrinth и CurseForge.** Поиск и установка модов, ресурспаков и шейдеров прямо в сборку, вместе с обязательными зависимостями; проверка и установка обновлений; удаление.
- **Три способа входа:** лицензия Microsoft, аккаунт Ely.by, офлайн-ник.
- **Редактор скинов.** Три панели: инструменты (кисть 1/2/4 px, ластик, заливка, пипетка, палитра, свой цвет, обычные/тонкие руки), холст с четырьмя видами персонажа (спереди, сзади, правый и левый бок), на которых рисуют прямо по пикселям, либо развёртка 64×64, слои «основной/верхний», сетка, масштаб, отмена/повтор; справа живой 3D-просмотр с вращением. «Сохранить скин» кладёт скин в каждую сборку и основную папку (ресурспак, работает и в офлайн-режиме) и загружает его в аккаунт Microsoft; скин аккаунта Microsoft/Ely.by подтягивается автоматически.
- **Понятные ошибки.** Если игра вылетела, лаунчер разбирает журнал и crash-report и объясняет причину по-русски (нехватка памяти, не та Java, конфликт модов, драйвер видеокарты и т. д.) с конкретными шагами.

## Интерфейс

Боковая панель сверху вниз: **Главная** (3D-персонаж, панель запуска, смена версии одним кликом), **Версии** (таблица: релизы, снапшоты, бета, альфа, установленные; поиск; примерная нужная Java), **Сборки** (карточки с временем игры; создание, копирование, удаление; **импорт готовых сборок .mrpack кнопкой или перетаскиванием файла в окно**), **Моды** (слева источники Modrinth / CurseForge / Установлено, справа типы: моды, ресурспаки, шейдеры; ставить можно в сборку или в основную папку игры), **Скин**. Внизу панели отдельно: **Java** (найденные установки, среды Mojang для загрузки, аргументы JVM) и **Настройки**. Аккаунты — кнопка справа вверху; журнал — в настройках и на главной.

Размер окна можно менять (тянуть за края или развернуть); интерфейс масштабируется целиком, расположение элементов не меняется.

## Собственный установщик (SvenchikSetup.exe)

Установщик написан на Python и Qt в стиле лаунчера; он же служит программой удаления.

1. Соберите лаунчер: `build.ps1`.
2. Соберите установщик: `powershell -NoProfile -ExecutionPolicy Bypass -File .\build_setup.ps1`.
3. Файл появится в `dist\SvenchikLauncher-Setup-<версия>.exe`.

Установщик спрашивает папку (по умолчанию `%LOCALAPPDATA%\Programs\Svenchik Launcher`, без прав администратора), ярлыки на рабочем столе и в меню «Пуск», запуск после установки. Программа регистрируется в «Параметрах → Приложения», её можно удалить оттуда. При удалении спрашивается, удалять ли данные игрока. Тихая установка для развёртывания: `SvenchikSetup.exe --silent --target "C:\путь"`.

Inno Setup-вариант (`make_installer.ps1`) остаётся как запасной.

## Установщик (Setup.exe)

1. Соберите `Svenchik Launcher.exe`: `build.ps1`.
2. Соберите установщик: `powershell -NoProfile -ExecutionPolicy Bypass -File .\make_installer.ps1`.
3. Готовый файл появится в `dist\SvenchikLauncher-Setup-<версия>.exe`.

Скрипт сам найдёт Inno Setup 6 или установит его через `winget`. Вручную можно открыть `installer\SvenchikLauncher.iss` в Inno Setup Compiler и нажать F9.

Установщик ставит лаунчер в `%LOCALAPPDATA%\Programs\Svenchik Launcher` без прав администратора, создаёт значки в меню «Пуск» (и на рабочем столе, по желанию). Новая версия ставится поверх старой с сохранением данных (`data\`). Удаление через «Параметры → Приложения» не трогает миры, аккаунты и сборки.

Версия берётся из `src\svenchik\__init__.py` (`__version__`). Не меняйте `AppId` в `.iss`: по нему установщик понимает, что это обновление.

## Быстрый старт: получить `Svenchik Launcher.exe`

Нужен Windows 10/11 и [Python 3.10+](https://www.python.org/downloads/) (при установке отметьте «Add python.exe to PATH»).

Нужен Windows 10/11. Python 3.10+ ставить заранее не обязательно: если его нет, скрипт поставит Python 3.12 через `winget`.

1. Положите папку проекта куда угодно, например `C:\Users\<вы>\Desktop\Svenchik Launcher`.
2. Откройте PowerShell в этой папке и выполните:

   ```powershell
   cd "$env:USERPROFILE\Desktop\Svenchik Launcher"
   powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
   ```

   Скрипт создаст `.venv`, поставит зависимости, прогонит тесты и соберёт exe. (`-ExecutionPolicy Bypass` нужен, чтобы Windows не блокировал скрипт, скачанный из интернета.)
3. Готовый файл появится рядом: **`Svenchik Launcher.exe`**. Запускайте его двойным щелчком.

Если exe запускается, но окно не открывается или в `data\logs\launcher.log` есть ошибки про QML/Qt — пересоберите с ключом `-Full` (кладёт в exe весь PySide6; файл станет больше):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Full
```

Другие ключи: `-SkipTests` — не гонять тесты.

| Скрипт | Что делает |
|---|---|
| `build.ps1` | сборка `Svenchik Launcher.exe` |
| `run.ps1` | запуск из исходников без сборки |
| `test.ps1` | автотесты |
| `build.bat`, `run.bat`, `test.bat` | двойной щелчок: просто вызывают соответствующий `.ps1` (`build.bat full` = `-Full`) |

## Обновление с предыдущей версии

Распакуйте новый архив поверх папки проекта (папки `data` и `.venv` не трогайте — настройки и аккаунты сохранятся) и снова выполните `build.ps1`.

## Новые возможности: что нужно знать

- **Сборки.** «Сборки» → «Создать сборку»: выберите версию Minecraft, загрузчик и его версию. Forge/NeoForge ставятся официальным установщиком (скачивается автоматически, нужна Java — лаунчер подберёт её сам; установка занимает 1–3 минуты). Для Babric и Legacy Fabric включите «старые версии» в настройках.
- **Каталог.** Выберите сборку, тип (моды / ресурспаки / шейдеры) и источник. **Modrinth** работает сразу. **CurseForge** требует бесплатный ключ API: <https://console.curseforge.com/> → Настройки лаунчера → CurseForge. Шейдеры работают только при установленном Iris/OptiFine, ресурспаки включаются в игре.
- **Ely.by.** «Аккаунты» → «Ely.by»: логин или e-mail и пароль (если включена двухфакторная защита — код 2FA). Для работы скинов и серверов Ely.by лаунчер при первом запуске скачивает `authlib-injector`.
- **Скины.** «Сохранить скин» создаёт ресурспак `SvenchikSkin`, включает его в каждой сборке и основной папке (подходит для офлайн-режима) и, если активен аккаунт Microsoft, загружает скин на серверы Mojang (виден всем игрокам). **Ограничения:** для Beta скин кладётся как текстур-пак (выбрать его нужно в меню игры), для версий Classic (c0.x, rd-) подмена скинов невозможна.

## Данные лаунчера

Всё лежит рядом с exe в папке `data\` (её можно удалить, чтобы сбросить лаунчер):

| Что | Где |
|---|---|
| Настройки | `data\settings.json` |
| Аккаунты и токены | `data\accounts.json` (открытым текстом — не публикуйте и не отправляйте этот файл) |
| Журнал лаунчера | `data\logs\launcher.log` |
| Вывод игры при последнем запуске | `data\logs\last-game.log` |
| Аварийный дамп лаунчера (если он закрылся сам) | `data\logs\native-crash.log` |
| Игра по умолчанию | `data\minecraft\` (меняется в «Настройки → Папка игры») |
| Сборки | `data\builds.json`, папки в `data\minecraft\instances\` |

## Вход через Microsoft и Ely.by

Кнопка справа вверху открывает окно «Аккаунты»: вход через Microsoft, вход через Ely.by и офлайн-профиль по нику.

- **Microsoft:** нажмите «Войти через Microsoft». В браузере откроется страница входа Microsoft с уже подставленным кодом; войдите в аккаунт, на котором куплен Minecraft. Ничего настраивать и регистрировать не нужно. Технически вход использует тот же публичный идентификатор приложения, что и официальный лаунчер Minecraft (константа `OFFICIAL_CLIENT_ID` в `accounts/microsoft.py`); это не отдельная регистрация Mojang для Svenchik Launcher, поэтому Mojang теоретически может ограничить такой вход — в этом случае используйте Ely.by или офлайн-профиль.
- **Ely.by:** логин или e-mail и пароль (при двухфакторной защите ещё код).
- **Офлайн:** любой ник 3–16 символов; скин выбирается во вкладке «Скин» (стандартные скины или свой).

## Импорт сборок из других лаунчеров

Во вкладке «Сборки» нажмите «Из другого лаунчера» и выберите папку, либо перетащите папку или архив `.zip` в окно. Поддерживаются папки **Prism Launcher / MultiMC**, **CurseForge** (папка экземпляра), **официального лаунчера** (`.minecraft`) и обычные папки игры с `versions/`. Версия Minecraft и загрузчик определяются автоматически; игра ставится заново, а из старой папки копируются только ваши данные: моды, миры, конфиги, ресурспаки, `options.txt`. Файлы самой игры (versions, libraries, assets) не переносятся. Готовые сборки Modrinth (`.mrpack`) импортируются так же.

Ограничения: загрузчики Legacy Fabric и Babric в Prism/CurseForge распознаются как чистая версия, а сборки CurseForge в формате `.zip` с `manifest.json` пока не поддерживаются.

## Редактор скина

Центральная область — большая 3D-модель. ЛКМ рисует (режим «Рисовать»), ПКМ или режим «Вращать» поворачивает модель, колесо мыши меняет масштаб. Вкладка «Развёртка» — текстура 64×64, «Виды» — четыре плоских вида. Инструменты: кисть (1, 2, 4 px), ластик, заливка, пипетка, осветлить, затемнить, замена цвета; кнопка «Очистить слой» очищает основной или верхний слой. Всё отменяется кнопкой «Назад».

## Каталог CurseForge (для разработчика)

Modrinth работает сразу. CurseForge требует ключ API, который пользователь вводить не должен: получите бесплатный ключ на <https://console.curseforge.com/>, положите его в текстовый файл **`curseforge.key`** в корне проекта и пересоберите exe (`build.ps1` вложит файл в exe). Без ключа вкладка CurseForge показывает спокойное сообщение, а Modrinth остаётся доступным.

## Разработка

```
src/svenchik/        исходники (см. ARCHITECTURE.md)
tests/               автотесты (unittest, без PySide6)
assets/              изображения и шрифты интерфейса (см. assets/ASSETS.md)
```

- Работать с проектом ИИ-агентам и людям: **ARCHITECTURE.md** (устройство) и **AGENTS.md** (правила).
- Тесты: `.\test.ps1` или `python -m unittest discover -s tests -t .` с `PYTHONPATH=src`.

## Статус проверки

- Ядро (установка версий, библиотеки/нативы, ресурсы, Java-среда Mojang, сборка команды запуска, офлайн-UUID, цепочка Microsoft/Xbox, настройки, аккаунты, **сборки и загрузчики, каталоги Modrinth/CurseForge с зависимостями и обновлениями, вход Ely.by с реальным `-javaagent`, разбор вылетов, математика 3D-редактора скинов и ресурспак**) покрыто автотестами (100+). Интеграционный тест ставит версию с локального «поддельного Mojang» и запускает **настоящий Java-процесс**.
- Реальные серверы Mojang/Microsoft/Modrinth/CurseForge/Fabric/Forge/Ely.by и реальные версии Minecraft при разработке не использовались (адреса и форматы API взяты из документации и проверены только на локальных копиях). Особенно не проверены: Babric и Legacy Fabric, версии NeoForge для очень новых Minecraft, параметр `ely.by` для authlib-injector, загрузка скина в Mojang и положение верхней/нижней граней в редакторе скинов.
- Реальные серверы Mojang/Microsoft и реальные версии Minecraft при разработке не использовались (в среде разработки не было сети) — первая установка настоящей версии на вашем ПК и есть первая боевая проверка.
- Интерфейс (QML), сборка `.exe` и PowerShell-скрипты писались без возможности запуска на Windows. Если что-то не открывается — смотрите `data\logs\launcher.log`: предупреждения QML пишутся туда.
